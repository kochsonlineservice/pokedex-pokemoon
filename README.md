# Pokédex

A responsive Pokédex web application built with HTML, CSS and JavaScript.

The application uses the PokéAPI to fetch Pokémon data and displays the Pokémon in interactive cards.

## Features

- Display Pokémon cards
- Pokémon name, image and type
- Search for Pokémon
- Load more Pokémon
- Detailed Pokémon information in a dialog
- Previous and next Pokémon navigation
- Responsive design
- API data fetched dynamically
- Caching of already loaded data

## Technologies

- HTML5
- CSS3
- JavaScript
- PokéAPI
- Git & GitHub

## API

This project uses the PokéAPI:

https://pokeapi.co/
